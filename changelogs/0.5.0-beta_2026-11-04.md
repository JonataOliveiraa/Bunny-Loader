# Bunny Loader 0.5.0-beta — 2026-11-04

The first beta after `0.4.0`, for testers. Bunny Loader now runs **C# mods only**, built to feel close to tModLoader. JavaScript mods no longer load, and the beta installs as its own app, next to the published one.

## For players

- **A separate app:** the beta shows up as **Bunny Loader Beta** and keeps its own mods, characters and worlds, so it does not touch your published Bunny Loader.
- **C# mods only:** JavaScript mods no longer load, and the launcher refuses to import them. The online catalog is off until the mods are ported, so the **Example Mod** is the only mod included for now.
- **Loading screen:** the game holds the intro, then shows a black screen with the loading flower until your mods are ready. The title opens with the mod's menu theme, instead of showing the vanilla menu and freezing for a few seconds.
- **New Mod Menu:** one pixel-art panel with icon-only sections, a grid of item slots, and Events as a tab next to Player and World. Every list can switch between icons and a detailed list.
- **Christmas launcher theme:** a ninth theme, turned on automatically from Dec 15 to Dec 31.
- **Multiplayer:** Bunny Loader now only joins Bunny Loader servers, so it can no longer be used on vanilla servers, and it cannot join servers on older versions. The host decides whether players can use the cheat menu.

## Fixes

- **Texture packs** apply while the game loads each texture, instead of on the menu, and replace textures in place without an extra copy in memory.
- A minion could get stuck when used with some item mods, because the held item's visual copy was missing data. It now copies every field, as on PC.

## Performance

- Less work per frame with C# mods: health and mana overlays no longer rebuild a texture lookup on every call, and the mod pylon scan is skipped when no mod pylon is near.

## For modders

- **Mod format 3:** packages now look like a tModLoader project: `<id>.cs` or `<id>.dll` at the root, with `Assets/`, `Common/`, `Content/` and `Localization/` next to it. There is no `content/` folder or `entry` anymore, and older packages must be converted.
- **The C# API follows tModLoader's names and layout:** start from tModLoader's documentation and the bundled Example Mod. See [Making mods in C#](../docs/mods-em-csharp/README.md) for the differences on the phone.
- **Editor:** the in-game Editor opens from the Mod Menu and has a C# console.
- **BL Editor:** the separate BL Editor app can connect to Mod Sources, install a project and test it.

## Known issues

- A mod that ships only `.cs` files compiles on the phone the first time it loads, and again after each app update. This can take a minute or more, with the loading flower on screen.
- The loading screen can still pause for a few seconds at a time, and it takes longer with large mods.
- The loading screen has not been tested on a real phone or with very large mods yet. If mods take longer than 5 minutes to load, the title opens anyway.

## Installing and updating

- The package name is `com.bunnyloader.beta`. It installs next to the published app, with no uninstall needed.
- Terraria must be installed, as in the published app.
- The APK is about 245 MB.
