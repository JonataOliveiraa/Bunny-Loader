# Bunny Loader 0.5.10-beta — 2026-11-22

The eleventh beta. The crash report is readable again and fully in English, and the app is ready to download precompiled code for mods.

## For players

- **A crash report you can actually send:** after a native crash, the report in Settings → Diagnostics used to fill with pages of unreadable symbols. It now shows only what explains the crash: the signal, the cause, the thread that fell, the list of calls that led there, and the last warnings and errors before it. Only the most recent native crash shows these details; older exits take one line each, with the time they happened.
- **The report is in English:** section titles, exit reasons, the boot steps and the log lines are now all in English, so a mod author anywhere can read it. Enabled mods are listed one per line.

## For modders

- **Precompiled mod code:** the launcher can now download a precompiled copy of a mod's code from the catalog and the game uses it instead of compiling the mod at every start. With Thorium, Consolaria and Split together, this took the black screen from about 7.5 s to 5 s on a phone. A mod without a precompiled copy, or a copy made for another app version, simply runs as before. See Tools and Tests → Precompiled mod code on the wiki.

## Installing and updating

- The package name is `com.bunnyloader.beta`. It updates the 0.5.9-beta in place, with no uninstall needed.
- Terraria must be installed.
