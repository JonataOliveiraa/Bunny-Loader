# Bunny Loader 0.4.0 — 2026-10-27

The first version after `0.3.3`, from Oct 25 to Oct 27, 2026. Mods can now be written in **C#**, next to JavaScript, and the launcher has a new Mod Sources screen to create and package mods right on the phone.

## For players

- **C# mods:** packages made in C# install and update like any other mod. The .NET runtime only starts when a C# mod is enabled, so a game with JS mods only runs exactly as before.
- **QuickJS can be turned off:** **Settings → Developer → QuickJS**. Off, JavaScript mods do not load and the game starts without the JS engine; C# mods still load.
- **Mod Sources:** **Settings → Developer → Mod Sources** lists your mod projects, creates a new one (optionally with a ready-made basic sword), and builds and installs it, or exports it as a `.bl`, without a PC. Projects live in the app's `ModSources` folder, which file managers can open through Android's document picker, and you can add other folders as source locations. Contributed by **bilimoing**.

## For modders

- **Mods in C#:** typed access to every class, field and method of the game, with autocomplete, and tModLoader-style hooks (`On_Item.SetDefaults += (orig, self, type, variant) => ...`). Measured on a real phone, C# code is from 5× to hundreds of times faster than the same code in JS; a call into the game costs about the same in both. C# has hooks and full access to the game, but not the content classes (`ModItem`, `ModNPC`, `ModSystem`...) yet: new content is still made in JS. JS and C# mods run side by side, and their hooks on the same method share one chain.
- **Two ways to ship a C# mod:** a compiled `.dll` (`"entry": "MyMod.dll"`, built on a PC with the .NET 10 SDK), or just the `.cs` files (`"entry": "MyMod.cs"`). Sources are compiled by the catalog when you publish, by `tools/mods/publish.py` and `manager.py` on a PC, or by the phone itself the first time the mod loads. All three use the same compiler and produce the same `.dll`, stamped with a hash of the sources so it is only rebuilt when they change.
- **Guides:** [Making mods in C#](../docs/mods-em-csharp/README.md), eight guides from the first mod to how the runtime works, with a C# × JS × tModLoader comparison and the measured performance.
- **Mod icons:** the Mod Menu and the touch buttons now use a package's `icon_small.png` when it has one, falling back to `icon.png`.

## For translators

- New texts for the Mod Sources screen in all seven languages. The Vietnamese and Thai ones are new and welcome a review.

## Known issues

- A mod that ships only `.cs` files takes a while to compile on the phone the first time it loads (tens of seconds on a mid-range phone); after that the compiled `.dll` is reused. Packages from the catalog come already compiled.
- Some error messages of the Mod Sources screen are still in Portuguese.

## Installing and updating

- Same signature as 0.3.3, 0.3.2, 0.3.1, 0.3.0 and 0.2.0: installs over them, no uninstall needed.
- The APK is bigger, about 227 MB, because it now carries the .NET runtime and the C# compiler.
