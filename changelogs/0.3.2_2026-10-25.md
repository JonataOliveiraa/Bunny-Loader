# Bunny Loader 0.3.2 — 2026-10-25

A fix version after `0.3.1`: the loader's in-game features on Android 11 and older, and an error on the title screen with animated mod walls.

## Fixes

- **Android 11 and older:** the Mod Menu, the JS icon, the error panel, mod sounds and screen-effect textures did not work. Before Android 12 an app cannot reach the system library the loader used to find Java, so it started without it. The loader now gets Java when it is loaded, as Android expects.
- **Android 7:** the Mod Menu loads on Android 7 as well, which cannot load it straight from memory.
- **Mod images on old phones:** opening a mod's pictures could crash on older devices. Fixed by a community developer.
- **Error panel on the title screen with animated mod walls.** Sometimes (about one launch in three) the panel showed `hook Main.DoUpdate_AnimateWalls: exception in callback: RangeError` with the Example Mod on. The game animates the title screen before the wall tables grow to fit mod walls, and the animated wall was read past the end of the table. Mod walls that do not fit yet are now skipped for those frames, as animated mod tiles already were.

## For modders

- The `RangeError` for an index past the end of a game array now shows the real last index (`0..366` for an array of 367), not the array's length.

## Installing and updating

- Same signature as 0.3.1, 0.3.0 and 0.2.0: installs over them, no uninstall needed.
