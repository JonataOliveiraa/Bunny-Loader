# Bunny Loader 0.5.1-beta — 2026-11-06

The second beta. It has a new app icon, a much bigger Example Mod with a boss, mods that compile before the game opens, and a fix for mod music slowing down the game.

The new Example Mod content is ported from tModLoader's Example Mod, so it also shows what a ported mod can do on the phone.

## For players

- **New app icon.** The launcher icon is now the bunny with the top hat.
- **Mods compile before the game opens:** Play and Restart now compile any mod with changed `.cs` files on a separate screen, with the game still closed. If a mod has an error, you see it in the launcher instead of waiting for the game to load. A mod that has not changed is not compiled again.
- **Boss Bar Style setting:** a new row in the game's General settings lets you choose a boss bar style added by a mod.
- **Longer NPC chats:** when an NPC has more buttons than fit, they split into pages of two. The chat panel, text box, name and dividers widen together, and a page button shows up only when there are two or more pages.
- **Portraits for mod NPCs:** mod NPCs can now show their own portrait.

## New in the Example Mod

- **Minion Boss:** the boss with its minions and eye projectile, a summon item, a treasure bag, a mask, a trophy, a relic, a pet, an emote, an achievement and its own boss bar, plus an example boss bar style.
- **Town NPCs:** the full Example Person, a Bone Merchant with a gun, a Traveling Merchant with a sword, and a town pet with its license. The merchants come with their shops, and town NPCs respawn.
- **Enemies and critters:** a worm, a Zombie Thief, a Party Zombie, an NPC with custom draw order, and a critter with its cage.
- **Items:** food, a healing potion, an instanced item, an item that reacts when you buy it, and a custom currency.
- **Touch controls:** an example touch button, a hold button and an aim joystick.
- **Smaller examples:** new dusts and a biome emote, a map layer, game tips, world ore, language variants, and changes to loot, shops, happiness and bestiary entries of existing NPCs.

## Fixes

- **Mod music no longer slows down the game:** switching a mod's Music Box on and off quickly caused stutters of up to about 120 ms, because each restart of the track made the game wait for Android. Mod music now talks to Android on its own thread, and quick toggling no longer restarts the track. The game's own Music Boxes were not affected.
- **Installing bundled mods is safer:** a failed or interrupted copy now keeps the installed version, where before it could make the mod disappear from the list, and **Download** seemed to do nothing. The mod's page now shows the progress and the error.
- **Christmas theme:** disabled packages no longer share the green of enabled ones.
- **Example Mod:** its tooltip item now has a texture.

## Performance

Measured on a Galaxy A15:

| | Before | Now |
|---|---|---|
| Slowest 1% of frames while toggling a mod Music Box | about 45 ms | about 19 ms |
| Slowest frame while toggling a mod Music Box | 98 ms | 21 ms |
| Game thread time on audio, slowest 1% of frames | 24.8 ms | 0.35 ms |

- **Less work when the game starts:** with mods compiled before the game opens, the Example Mod compiles in about 13 s, and the game then prepares about 10,700 methods instead of 33,700.

## For modders

- **More of tModLoader's API:** new content from boss bar styles, map layers, NPC portraits, NPC shops, drop rules and conditions to game tips and networking between mods. Start from the bundled Example Mod and tModLoader's documentation.
- **Touch joysticks:** `ModTouchJoystick` joins the touch buttons. This one is ours, not from tModLoader.
- **Compile errors in the launcher:** Play, Restart and the BL Editor's Test all compile first. In the BL Editor, errors go back to the editor with the game still closed. Compiling inside the game stays as the fallback.
- **Packs from Mod Sources:** a project of type texture or font can now be built from Mod Sources, with its images or fonts instead of a mod class.
- `ModPlayer.SetStaticDefaults` now runs. It never did before.
- `GameDictionary` no longer crashes with `Vector2` values.

## Known issues

- **Multiplayer:** the new Example Mod content has not been tested in multiplayer yet.
- **Town NPCs:** `ActsLikeTownNPC`, `TownNPCStayingHomeless` and related settings exist but have no effect yet.
- **Compiling:** the first compile of a mod with only `.cs` files takes about 13 s on a Galaxy A15, and runs again when its files change or after an update.

## Installing and updating

- The package name is `com.bunnyloader.beta`. It updates the 0.5.0-beta in place and installs next to the published app, with no uninstall needed.
- Terraria must be installed, as in the published app.
- The APK is about 235 MB.
