# Bunny Loader 0.5.2-beta — 2026-11-06

The third beta. It has a new animated opening screen, invasions made by mods, the rest of the Example Mod's content and many fixes for bugs reported from the second beta.

## For players

- **New opening screen:** the app now opens with the bunny in the top hat eating a carrot. It stays until your packages are ready and then fades into the launcher.
- **More room in the launcher:** the system's navigation bar is now hidden there. Swipe up from the bottom edge to bring it back.
- **Mod invasions:** mods can now add wave-based events with the game's own progress bar, their own music, and saved progress. Vanilla events do not start during one.
- **Long names in the Cheat Menu** now scroll sideways instead of being cut off.
- **Cheat Menu amounts:** mod items that stack now reach 10x, 99x and 9999x like vanilla ones. Weapons and equipment still give 1.

## New in the Example Mod

- **Two invasions**, rewritten in C# from Animatak_'s Example Invasion and credited in the mod.
- **More examples from tModLoader's Example Mod:** blocks that fall like sand, a cactus, pressure plates, dyes and an interactable projectile.

## Fixes

- **Mod touch buttons:** the list of a mod's buttons in the controls editor now opens every time. A tap no longer falls through to the next button or closes the list.
- **Crash with town pets:** opening the NPC tab with a mod's town pet no longer crashes the game.
- **Crash on a pet:** interacting with the Example Mod's pet no longer crashes the game.
- **NPC chat:** the Guide's **Crafting** button no longer gives an error.
- **Mod emotes** can now be tapped.
- **Bone Merchant:** the Example Mod's skeleton merchant now animates correctly.
- **Saving:** items kept in a mod's world or player data now save instead of giving an error, which also fixes the Traveling Merchant's save.
- **Mod blocks:** they now connect to the blocks around them, and falling blocks fall.
- **Mod Config:** long labels and headers scroll inside their row instead of running over the controls, and the popup's dark background covers the whole screen.
- **Example Mod:** invasions change the music, its interactable projectile reacts to a tap, and Example Person no longer gives an error when picking an emote.

## For modders

- **More of tModLoader's API now exists or works:** see the new [API reference](https://github.com/JonataOliveiraa/Bunny-Loader/wiki/API-Reference), which lists every class and member, compared with tModLoader. Start from the bundled Example Mod and tModLoader's documentation.
- **`ModInvasion` and `InvasionLoader`:** these are ours, not from tModLoader. See [Invasions](https://github.com/JonataOliveiraa/Bunny-Loader/wiki/Invasions).
- **Config labels** resolve `[i:Mod/Item]`, `[c/hex:text]` and `$key` arguments, like tModLoader.
- `ModifyNPCHappiness` runs when the game works out the shop price, with `primaryPlayerBiome` always 0.
- `ConsumeItem` now runs on normal item use. It only ran for right-click containers before.

## Known issues

- **Multiplayer:** invasions were tested in multiplayer, but the rest of the new Example Mod content has not been fully tested there yet.
- **Mod emotes:** a report that mod emotes replace vanilla ones could not be reproduced. Please tell us if you still see it.

## Installing and updating

- The package name is `com.bunnyloader.beta`. It updates the 0.5.1-beta in place and installs next to the published app, with no uninstall needed.
- Terraria must be installed, as in the published app.
- The APK is about 235 MB.
