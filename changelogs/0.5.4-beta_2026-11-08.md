# Bunny Loader 0.5.4-beta — 2026-11-08

The fifth beta. It fixes what was still reported on the fourth beta: tooltips, wings, the Interact button and how mod projectiles are drawn.

## New in the Example Mod

- **Example Dual Use Weapon,** from tModLoader: a normal swing, and in the alternative fire mode a thrust that shoots bees.

## Fixes

- **Mod item tooltips:** control placeholders such as `{InputTrigger_InteractWithTile}` were still shown as raw text in item tooltips. They now show the touch icon, like the game's own texts.
- **Two pairs of wings:** a vanilla accessory slot accepted wings, or the same accessory, that was already in a mod accessory slot. It now refuses them, like the vanilla slots do among themselves.
- **Interact button with a mod item that has a right-click use:** it often took two taps to switch the mode, and the button gave no feedback. Each tap now switches the mode once, and the button lights up under the finger like it does for vanilla items.
- **Mod projectiles drawn out of place:** projectiles that set a draw offset were drawn a few pixels away from where tModLoader draws them, so the highlight of the Example Mod's interactable projectile sat above the pig. They now appear where tModLoader puts them.

## For modders

- **`DrawOffsetX`, `DrawOriginOffsetY` and `DrawOriginOffsetX`** of `ModProjectile` now move the sprite the game draws, as in tModLoader, also when they change in `AI`.

## Installing and updating

- The package name is `com.bunnyloader.beta`. It updates the 0.5.3-beta in place, with no uninstall needed.
- Install the new APK: the new loader does not run on the 0.5.3-beta APK.
