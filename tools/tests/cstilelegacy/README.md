# Legacy JS tile world writer

This companion pack deliberately uses the same UID as cstile. Run it with QuickJS enabled, then replace it with cstile while preserving saves. It writes a Block at 64,64 with frame 18,36 through the existing JS/native tile API and saves the world. ABefore changes the numeric registration order.

See [the C# test instructions](../cstile/README.md) for the complete sequence and recorded results.
