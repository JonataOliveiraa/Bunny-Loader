# Talking to the game

> [Reference index](README.md) · generated by `tools/docs/ApiReference`, do not edit by hand

How C# reaches the mobile game: handles to game objects, collections and hook helpers. All of it is only in Bunny Loader, because tModLoader runs on the game's own objects.
