## GlobalProjectile

`abstract class Terraria.ModLoader.GlobalProjectile` : `GlobalType<Projectile, GlobalProjectile>`

This class allows you to modify and use hooks for all projectiles, both vanilla and modded. To use it, simply create a new class deriving from this one. Implementations will be registered automatically.
