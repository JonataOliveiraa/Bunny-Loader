# Changelog

## 1.1.0 - 2026-10-04

- Added `ModConfig` to configure the Boss Cursor behavior.
- Added Always mode: the cursor is displayed for the Boss regardless of distance.
- Added Off-Screen mode: the cursor is displayed only when the Boss is off-screen or far away from the player.
- Added Never mode: completely disables the Boss Cursor.

## 1.0.0 - 2026-09-27

- Initial release of Boss Cursor.
- Added the Boss "Draw" system.
- Added support for each Boss's extra icons.
