# Info

This mod separates your achievements per world, and also adds commands to manage them.

It's great both for playing in a new world and for creators to test the achievements of their mods.

## Features

- Allows you to have separate achievements per world.
- File isolation: you will not lose your current achievements if you remove this mod!
- Special commands to give, remove, or clear and unlock all achievements!
- Fully compatible with mod achievements

## Commands

- Use **/achievements unlock [achievement]** to unlock an achievement.
- Use **/achievements lock [achievement]** to remove an achievement.
> [!TIP]
> Use **all** instead of the name to affect all achievements.
