# Changelog

## 1.0.0

- Abuse Goblin for Bunny Loader: hit the Goblin Tinkerer to lower reforge
  prices, with an optional unkillable mode.
- Config for the start price, discount per hit, minimum price and reset time.
- The current price pops up over the Goblin Tinkerer on every hit.
- Support for Terraria's languages.
